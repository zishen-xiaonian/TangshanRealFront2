# 停电用户分析右侧栏接口

## 接口信息

- 请求方式：`POST`
- 默认地址：`/api/v1/outage-users/analysis-overview`
- 前端环境变量：`VITE_OUTAGE_USER_ANALYSIS_API`
- 超时时间：60 秒

开发阶段默认使用示例数据：

```env
VITE_OUTAGE_USER_ANALYSIS_USE_MOCK=true
```

后端接口完成后改为 `false` 并重新启动 Vite：

```env
VITE_OUTAGE_USER_ANALYSIS_USE_MOCK=false
```

## 请求参数

```json
{
  "rangeType": "thirtyDays",
  "countyName": "",
  "beginTime": "2026-08-13 00:00:00",
  "endTime": "2026-09-11 23:59:59"
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rangeType` | string | `sevenDays`、`thirtyDays` 或 `history` |
| `countyName` | string | 区县名称；空字符串表示全部区县 |
| `beginTime` | string | 开始时间；历史范围时传空字符串 |
| `endTime` | string | 结束时间 |
